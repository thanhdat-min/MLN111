Web-based interactive presentation for the **MLN111 course (Marxism-Leninism)** using HTML/CSS/JavaScript, with visuals generated by **Google Gemini**.

## ✨ Features

- Interactive presentation interface
- Gemini-generated visuals (screenshot preview in repo)
- Simple static stack — HTML, CSS, JavaScript
- Deployed live on Vercel

## 🚀 Live Demo

👉 [mln-111-drab.vercel.app](https://mln-111-drab.vercel.app)

## 🛠 Tech Stack

- HTML5, CSS3, JavaScript
- Google Gemini (image generation)
- Vercel (deployment)

## ▶️ Run Locally

Open `index.html` in a browser, or:

```bash
npx serve .
```
